The complete paginated fetch helper already rejected duplicates, but the publicly exposed planner did not. Now throws an error and preserves offline bookmarks; regression test covers conflicting revisions for the same identity. No UI/scanner/Assist changes. **Not considered CI verified until workflow passes.**

## Astra acceptance rules

Each finding needs (a) exact repro, (b) minimal change design with protected boundary, (c) regression including failure and restart, (d) source SHA/diff against frozen baseline, (e) Android/Fold/Pi/car physical tests as applicable, and (f) issue/status/log changes before closure. For high-risk data integrity tasks A-01/A-02/A-06, avoid changing source until an independent strategy and rollback proof are accepted. Never turn a static concern into a claim of a production incident.
